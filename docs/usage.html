ReMux Workspace Guide

Premium interactive developer workspace instructions for local & remote tmux multiplexing.

Getting Started

🔌
Hosts Configuration

1. Setup Connection Profiles

Open the primary left sidebar (Cmd + B). Click **Add Host** to define local or remote SSH servers. ReMux securely stores credentials inside your macOS system Keychain and resolves local SSH aliases automatically.

🪟
Grid Workspace

2. Recursive Split Layouts

Organize splits recursively. Focus a panel and hit Ctrl + Shift + E to split vertically, or Ctrl + Shift + D to split horizontally. Change active pane focus smoothly using Ctrl + Shift + Tab.

📡
Keystroke Relay

3. Synchronized Input Broadcast

Activate the **Broadcast Mode** toggle (Radio Beacon Icon) in the bottom StatusLine. Keystrokes entered in the active terminal will be sent instantly to all terminal splits within the active tab simultaneously.

Advanced Operational Features

⚙️

Performance Sliders

Adjust background diagnostics and tmux hierarchy parsing inside the right settings panel (Cmd + ,). Toggle presets (Eco, High Performance) to dynamically schedule polling timers.

🔄

Auto-Recovery heartbeats

On connection drop, ReMux runs non-blocking backend pings. The user is presented with a glassmorphic connection modal that handles exponential retry timers to transparently reconnect without losing scrollback.

🛡️

Security PasteGuard

Avoid running accidental dangerous scripts. Pasting text containing multiple lines (Ctrl + Shift + V) triggers the PasteGuard modal to preview and scrub inputs safely.

시작하기

🔌
호스트 구성

1. 연결 프로필 설정

왼쪽 기본 사이드바(Cmd + B)를 엽니다. **Add Host**를 클릭하여 로컬 또는 원격 SSH 서버를 추가하세요. 입력된 정보는 macOS 시스템 키체인(Keychain) 내에 암호화되어 안전하게 보존되며, 로컬 SSH alias 파일 또한 자동으로 분석합니다.

🪟
그리드 워크스페이스

2. 패널 레이아웃 가로/세로 분할

원하는 패널을 포커스하고 단축키 Ctrl + Shift + E를 누르면 세로 분할, Ctrl + Shift + D를 누르면 가로 분할이 수행됩니다. 분할된 패널 포커스 변경은 Ctrl + Shift + Tab 단축키를 이용해 매끄럽게 순환시킬 수 있습니다.

📡
키 입력 동시 릴레이

3. 동시 입력 브로드캐스트 모드

하단 StatusLine의 **Broadcast** 토글 버튼(라디오 전송 형태 아이콘)을 클릭하면 모드가 켜집니다. 활성화 시, 현재 탭 내의 모든 분할 패널 테두리가 네온 펄스 붉은빛 경고로 전환되며 키보드 입력이 모든 패널에 동시 전송됩니다.

고급 기능 설명

⚙️

성능 조절 슬라이더

오른쪽 설정 탭(Cmd + ,)을 통해 백엔드 텔레메트리(메모리 모니터링) 및 실시간 tmux 트리 인벤토리 분석 주기를 슬라이더로 직접 튜닝할 수 있습니다. 시스템 자원 소모 수준을 맞춤형 프로필 프리셋으로 제어하세요.

🔄

네트워크 자동 회복 및 재접속

연결 유실이 발생하면 ReMux 백엔드는 백그라운드 핑 루프를 시작하고 화면에는 부드러운 연결 회복 모달이 열립니다. 자동으로 지수 백오프 기반 재연결을 시도하며, 성공 시 기존 tmux 세션에 스크롤 손실 없이 즉시 재부착(Reattach)됩니다.

🛡️

보안 PasteGuard 기능

실수로 다량의 복사 붙여넣기 실행으로 일어나는 해킹 사고를 예방합니다. 여러 줄 텍스트를 붙여넣으려고 하면(Ctrl + Shift + V), 붙여넣기 직전 입력을 필터하고 검수해 볼 수 있는 PasteGuard 창이 자동으로 먼저 열립니다.
